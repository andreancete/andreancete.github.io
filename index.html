Como desenvolvi os projetos próprios

Desenvolvimento orientado por agentes: utilização de agentes de IA para apoiar diferentes etapas do ciclo de desenvolvimento de software.

  • Engenharia de contexto e prompts: elaboração de instruções, definição de contexto e utilização de Skills para orientar os agentes na execução de tarefas técnicas.
  • Integração de ferramentas com MCP: conexão dos agentes a ferramentas, serviços e recursos externos para ampliar suas capacidades.

Os repositórios no GitHub são privados. O código fica disponível sob solicitação, em processo seletivo.
